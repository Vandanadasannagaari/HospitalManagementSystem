# 🏥 Hospital Management System

## About the Project
The Hospital Management System is a web-based application developed using Java and Spring Boot. It is designed to manage hospital-related information through a structured web application.

## Technologies Used
- Java 17
- Spring Boot 3.4.5
- Spring MVC
- Spring Data JPA
- Hibernate
- MySQL
- Thymeleaf
- Spring Security
- HTML
- CSS
- Maven

## Project Structure
- **config** – Configuration classes
- **controller** – Handles application requests
- **entity** – Entity classes
- **repository** – Database operations
- **templates** – HTML pages
- **static/css** – CSS files
- **application.properties** – Application configuration

## Dependencies
- Spring Boot Starter Web
- Spring Boot Starter Thymeleaf
- Spring Boot Starter Data JPA
- MySQL Connector
- Spring Boot Starter Security
- Spring Boot Starter Validation

## Prerequisites
- JDK 17
- MySQL
- Maven
- Eclipse IDE

## How to Run
1. Clone or download this repository.
2. Import the project into Eclipse.
3. Configure MySQL database details in `application.properties`.
4. Update database credentials.
5. Run the main Spring Boot application class.
